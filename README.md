# Portal Integra SGE

> **Status:** 🚧 em desenvolvimento

## Objetivo

Portal da Gerência de Sistematização e Gerenciamento Escolar (GSGE) da SEDUC-TO para receber, de forma organizada e rastreável, as planilhas de Transferência de Alunos (TA) enviadas pelos municípios.

## Stack

- React + Vite + TypeScript + Tailwind CSS (frontend, hospedado no Vercel)
- Google Apps Script (backend), Google Drive e Google Sheets
